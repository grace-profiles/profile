== create-feature

=== Description

Creates a new profile feature.

=== Arguments

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Required**

|Feature Name
|The name of the Feature
|true
|===

=== Usage

[source,bash]
----
$ grace create-feature [Feature Name]
----

=== Examples

[source,bash]
----
$ grace create-feature example
| Feature created at Users/grace/myprofile/features/example
----
