== create-generator-command

=== Description

Creates a new `generate-*` command for the profile.

=== Arguments

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Required**

|Command Name
|The name of the command to be created
|true

|Target Directory
|The target directory
|true

|Convention
|The convention to use for file names, defaults to command name
|false
|===

=== Flags

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Type**

|force
|Whether to overwrite existing files
|boolean, default: false
|===

=== Usage

[source,bash]
----
$ grace create-generator-command [Command Name] [Target Directory]
----
