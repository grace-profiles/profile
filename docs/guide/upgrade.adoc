NOTE: Currently, Grace framework does not provide a direct `upgrade` command, but it may offer this in the future.

The simplest way is to create two different versions of a new profile, and then compare the differences between the two versions using the `git-diff` command.

[source,console,subs="attributes"]
----
$ sdk use grace {version}
$ grace -v
$ grace create-profile com.example.myprofile --grace-version=2023.3.0
$ cd myprofile
$ git init && git add . && git commit -m "Generated by Grace 2023.3.0"
$ cd ..
$ grace create-profile com.example.myprofile --force
$ cd myprofile
$ git diff
----
