1 Introduction

Grace Profiles encapsulate project commands, templates, and plugins.

To create a profile using the profile profile you can use the next command:

$ grace create-profile com.example.myprofile

3 Upgrade

Currently, Grace framework does not provide a direct upgrade command, but it may offer this in the future.

The simplest way is to create two different versions of a new profile, and then compare the differences between the two versions using the git-diff command.

$ sdk use grace 2024.1.0-SNAPSHOT
$ grace -v
$ grace create-profile com.example.myprofile --grace-version=2024.0.0
$ cd myprofile
$ git init && git add . && git commit -m "Generated by Grace 2024.0.0"
$ cd ..
$ grace create-profile com.example.myprofile --force
$ cd myprofile
$ git diff

4 Profile Info

You can always get information about the provided command and available features executing grace profile-info profile

You will see an output similar to:

Profile: profile
Version: 2024.1.0-SNAPSHOT
Extends:
Description: A profile for creating new Grace profiles

Provided Commands:
----------------------------------------------------------------------------------------------------
Name                           Description
----------------------------------------------------------------------------------------------------
create-command                 Creates a new command for the profile
create-creator-command         Creates a new create-* command for the profile
create-feature                 Creates a new profile feature
create-generator-command       Creates a new generate-* command for the profile
create-gradle-command          Creates a new command that invokes Gradle for the profile
create-template                Creates a new template for the profile

Provided Features:

Name                           Required  Defaults  Description
