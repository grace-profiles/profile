== create-command

=== Description

Creates a new command for the profile.

=== Arguments

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Required**

|Command Name
|The name of the Command
|true
|===

=== Usage

[source,console]
----
$ grace create-command [Command Name]
----

=== Examples

[source,console]
----
$ grace create-command Example
| Rendered template Command.groovy to destination commands/example.groovy
----
